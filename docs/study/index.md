## 怎么用：先做，卡住再查，最后讲

1. 打开当天页面，先看「今天要解决什么」，再直接看「动手清单」和「自检问题」，10 分钟内动手。
2. 卡住再读对应小节或资料；讲义是参考手册，不要从头通读。
3. 结束前合上讲义，写下当天 3 个概念 + 1 个公式/结论；再用 Java 类比讲 2 分钟，讲不通的地方就是漏洞。
4. 回到[计划页](/plan/)勾选任务；周日晚做复盘。
