- [ ] 配置从环境变量读取，代码里没有硬编码 key。

## 周测方法

### 算法（90 分钟）

数组、二分、哈希表、双指针、栈各 2 题。不要追求难度，追求：

1. 能在 15 分钟内写出可运行版本。
2. 能说出时间 / 空间复杂度。
3. 能自己构造一个边界用例。

### 记忆卡（90 分钟）

打开[第 1 周记忆卡](/cards/week-01)，先用「全部」过一遍，再只做「今天到期」。错 3 张以上，回到对应讲义重读，不要只是重复翻卡。

## 周复盘怎么写

打开[第 1 周计划](/plan/week-01)底部的「本周复盘」，填三段：

1. **最大卡点**：这周最卡的一件事，写具体。
2. **下周只改一件事**：只写一件，别写清单。
3. **本周最值钱认知**：能用一句话讲清楚的那种。

然后点「复制 Markdown」，把复盘贴到你的周报或笔记里。

## 提交

```bash
git add .
git commit -m "feat(w1): llm client + CLI chat + failure tests"

```

- [ ] 没有提交 `.venv/`、`__pycache__/`、`.env`。
- [ ] 没有提交真实 API key。
- [ ] README 里的命令能照着跑通。
