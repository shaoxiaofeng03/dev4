## 投递节奏

- **W17**：首批 30 家，优先南京本地 + 上海 / 杭州远程或通勤可行。
- **W18**：补投 20 家，累计 50 家。
- **W19–W20**：面试高峰，不再大规模投递，专注复盘和补强。

## 简历检查

- [ ] 三个项目都有量化指标（评测分数、延迟、成本、成功率）。
- [ ] 每个项目有一句「为什么这么做」的取舍。
- [ ] Java 经验放在显眼位置，不藏在最后。
- [ ] 没有「精通」「熟练掌握」这类无法验证的词。
- [ ] 一页能讲完，附件有作品集链接。
