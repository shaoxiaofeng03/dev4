# 怎么用这套站点

这套站点的定位不是「教程库」，而是**作战面板**：每天打开就知道做什么，做完能勾掉，周末能复盘。

## 每天（10 分钟维护）

1. 打开 [打卡页](/checkin) 或首页的「今天」区块。
2. 按顺序勾掉今天的任务（工作日 3–4 条，周末 4–7 条）。
3. 学完在当天学习页底部「今日记录」发一条：收获 / 卡点 / 想法，可以追加多条。
4. 睡前用 15–25 分钟过一遍当天到期的记忆卡。

> 每天 2 小时里，最后 25 分钟就是留给记忆卡的。不要攒到周末一起背。

## 学习文档

每天的**知识点、阅读顺序、动手清单和自检问题**在「学习」页（`/study/`）：

- **W1–W4**：每天一页，讲义级，先读它再动手。
- **W5–W20**：每周一页，导航级，含 7 天拆分建议和资料。

计划页的「学习」列、首页「今天」区块、每周任务卡右上角都有入口。

## 每周（30 分钟复盘）

周日晚在当周页面做三件事：

- 对照「本周交付」自查，没完成的写清原因（估时不准 / 被打断 / 内容太难）。
- 回答页面底部的「复盘问题」，然后在「本周复盘」块里填三段（最大卡点 / 下周只改一件事 / 本周最值钱认知）并保存。
- 确认下周一开始前，环境和资料都就绪。

## 每月（1 小时校准）

每四周回看一次 [20 周总览](/plan/)：

- 进度落后超过 1 周：砍内容，不要砍项目。项目是简历的核心，笔记和扩展阅读可以砍。
- 进度提前：不要加新内容，把时间投到「项目做得更深」和「算法」上。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/dev4/`。打卡和复习进度会直接写入 `docs/data/*.json`，不需要 Token。

每天结束时手动提交：

```bash
git add docs/data/checkins.json docs/data/review-state.json
git commit -m "chore(checkin): 打卡 $(date +%F)"
git push
```

## 线上与手机

GitHub Pages 是只读站点：

- 手机可以浏览内容、看计划、翻记忆卡（状态保存在那台设备的浏览器里）。
- 打卡写入只在本地 `npm run dev` 时发生。
- 换设备时用打卡页的「导出 / 导入 JSON」恢复。
