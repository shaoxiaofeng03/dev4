## 这套计划的原则

1. 先工程，后模型：重试、超时、校验、评测、可观测是第一课，不是最后补。
2. 两个深项目 > 五个 demo：每个项目都要有评测数据、失败案例和取舍论证。
3. 每周只改一个变量：调 prompt / RAG / Agent 时，否则永远说不清是谁的功劳。
4. Java 不丢：用 Spring AI / LangChain4j 把 AI 接进存量系统，这是差异化。
5. 边做边投：W17 启动首批投递，用真实面试反馈驱动最后四周。
6. 留缓冲：W11 是春节缓冲周，不排新课；断一周不等于计划崩盘。
